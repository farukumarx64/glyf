# Historical source material

These are the original Mosaic specification, schema and demo supplied for the initial review. They are preserved byte for byte for provenance and the approved-schema-difference test. They are **not** current authoring examples and the old `mosaic` marker is rejected by Glyf.

Use [the current specification](../SPEC_V0.1.md), [Glyf schema](../../schema/glyf-v0.1.schema.json) and [Glyf demo](../../examples/glyf-demo.glyf). The demo moved here from `examples/mosaic-demo.mosa` when the owner approved the full pre-release rename on 2026-11-22. Previous release notes and benchmark reports describe the builds they measured; they do not establish compatibility with the current format.
